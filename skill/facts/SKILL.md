# Копилка фактов

Телефоны, адреса, контакты, реквизиты, любые данные, которые хозяин просит сохранить и которые
не относятся к потокам работы (для них — навык `flows`). Одна запись = один файл в
`~/brain/копилка/`, имя файла — дата и время сохранения. Картотека тегов `КОПИЛКА.md`
собирается сама. Работать **только через скрипт**:

```
K="python3 $HOME/.hermes/scripts/facts.py"   # не ~ : в кавычках тильда не раскрывается
```

## When to Use

- «Сохрани / запиши / запомни» телефон, адрес, контакт, имя, номер, данные — не про работу в потоке.
- «Какой телефон у стоматолога?», «что у меня есть по Москве / из медицины?»,
  «покажи, что сохранял на прошлой неделе».
- «У стоматолога новый телефон», «удали запись про …».

## Команды

| Что нужно | Команда |
|---|---|
| Сохранить | `$K save "дословно" --title "…" --tags "что,категория,место" [--field "Телефон=+54 9 11 …"] [--attach путь]` |
| Найти по тегам (нужны все) | `$K find --tag медицина --tag буэнос-айрес` |
| Найти по любому из тегов | `$K find --tag стоматолог --tag лор --any` |
| Найти по тексту | `$K find "Гомес"` (можно вместе с `--tag`) |
| Все теги (компактно) | `$K tags` |
| Запись целиком | `$K show <id>`; последние: `$K recent 10` |
| Дополнить (новый телефон и т.п.) | `$K note <id> "Новый телефон: …"` |
| Поменять теги / название | `$K retag <id> --add x --remove y`, `$K title <id> "…"` |
| Слить похожие теги | `$K rename-tag стоматология стоматолог` |
| Удалить | `$K delete <id>` — **только после явного «да» хозяина** |

## Procedure

### Сохранение
1. Сам, без вопросов хозяину, придумай **2–5 тегов**:
   - **что это** конкретно: `стоматолог`, `сантехник`, `банк`, `нотариус`;
   - **категория** — одна из базовых: `медицина`, `дом`, `документы`, `финансы`, `транспорт`,
     `еда`, `сервисы`, `люди`, `работа`, `учеба`, `путешествия`, `покупки`, `семья`;
   - **место**, если есть: `буэнос-айрес`, `палермо`, `москва`;
   - имя человека или организации, если по нему будут искать.
   Теги — в единственном числе, строчными, без `#`; слова через дефис (`буэнос-айрес`).
2. Название (`--title`) — коротко, что это и чьё: «Стоматолог в Палермо — доктор Гомес».
3. Текст — **дословно**, как сказал хозяин. Телефоны, адреса, суммы — ещё и полями `--field`:
   телефон в международном виде (Аргентина: `+54 9 11 …` для мобильных), адрес как есть.
4. Скрипт ответит `✓ …` и может сказать «новый тег #x — похожие уже есть: #y». Тогда сразу
   поправь: `$K retag <id> --remove x --add y`. Хозяина об этом не спрашивай.
5. Если в сохраняемом есть дата встречи или дедлайн — спроси одним вопросом, поставить ли
   напоминание (навык `flows`, `event` — событие в календаре).

### Поиск
1. Конкретный вопрос («телефон стоматолога») → `$K find --tag стоматолог`; нет — `$K find "стоматолог"`.
2. Широкий вопрос («что из медицины», «всё по Москве») → сначала `$K find --tag медицина`.
   Если мало или пусто — `$K tags`, выбери все подходящие по смыслу теги (`стоматолог`, `лор`,
   `клиника` …) и `$K find --tag … --tag … --any`.
3. Отвечай сразу данными: название, телефон, адрес. Не пересказывай поле «Дословно», если
   в нём нет ничего сверх полей. Нашлось много — дай список названий, детали по запросу.
4. Не нашёл — скажи прямо и спроси, поискать ли в потоках (`flows`) или в интернете.

## Pitfalls

- Не читай файлы копилки напрямую и не открывай `КОПИЛКА.md` — только `find` / `show` / `tags`.
- Не придумывай данных, которых хозяин не называл. Неразборчивый номер — спроси.
- Работа, выводы, идеи по проектам — это `flows`, не копилка. Сомневаешься — спроси одним вопросом.
- «Сохранил» пиши только после строки `✓` от скрипта.
