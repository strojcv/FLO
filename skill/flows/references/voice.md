# Длинная голосовая (`[voice:<id> · … · исходник сохранён]`)

Последняя строка расшифровки `— <модель> · N с` — служебная, в точки не пиши.
Короткие голосовые (меньше минуты) приходят без метки — это обычные сообщения.

1. Определи поток (как в SKILL.md). «Новый поток …» → сразу `new-flow`, дальше обрабатывай как
   обычно. Есть «начинаем новую точку» — `new-point` в том месте рассказа: сказанное до — в
   старую точку, после — в новую.
2. `$F attach <id> <поток>` — исходник переезжает в поток, в «Контекст» встаёт ссылка на него.
3. Каждую мысль — отдельной командой `$F add <поток> <раздел> "…" --short "…" --src <id>`
   (разделы — как в SKILL.md). **Тезис + полный текст** — по правилу SKILL.md «Как писать»: тезис в 1–2
   строки, текст без «э», «ну», повторов, но в структуре и порядке хозяина (пункты — с новой строки,
   через `printf … | $F add … - --short "…" --src <id>`). Транскрипт целиком не пересказывай:
   исходник уже сохранён.
4. Пустой заголовок у точки — `$F title <поток> "…"` (3–7 слов). Выжимку точки одной фразой —
   `--summary "…"` в последней команде `add` для этой точки.
5. Голосовая про два потока — раздели: каждая часть в свой поток, `attach` к главному.
6. Ответь отчётом (метка места + что записано). Текст голосовой не повторяй.
