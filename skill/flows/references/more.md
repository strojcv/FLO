# Редкие команды

| Что нужно | Команда |
|---|---|
| Все потоки с закрытыми | `$F status --all` |
| Точка целиком / один раздел | `$F point <поток> [дата\|номер] [--section комментарии]` |
| Все комментарии (задачи, только идеи 💡) по точкам | `$F collect <поток> комментарии` (`задачи`, `идеи`) |
| Сделать поток текущим / узнать текущий | `$F use <поток>` / `$F current` |
| Приоритет / пауза / закрыть | `$F set <поток> --priority 1 --status open\|paused\|closed` |
| Удалить поток навсегда | сначала спроси «удалить «X» со всеми точками навсегда?»; только после «да» — `$F delete-flow <поток> --force`. Убрать с глаз — `set --status closed` |
| Отменить последнюю запись | `$F undo` |
| Привязать голосовую | `$F attach <voice-id\|last> <поток>` |
| Мысль без потока / разобрать | `$F note "текст"`; `$F inbox`, `$F inbox-move N <поток> идеи` |
| Поиск | `$F find "текст" [--flow …] [--sources]`; по тегу `$F find --tag продажи` |
| Теги | `$F tags`; новый — `$F tag-add тег "описание"` (только после согласия хозяина) |
| Экран под указателем | `$F view` |

- Теги — только из словаря (`$F tags`).
- `ОШИБКА: … подходит к нескольким …` — спроси, какой из них.
- `⚠ КОНФЛИКТ синхронизации` — сообщи и спроси, какую версию оставить:
  `$F sync --prefer server` или `$F sync --prefer pc`.
- Задачи без заголовка, хозяин просит «сделай заголовки» → `brief` по каждой.
