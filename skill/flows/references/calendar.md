# Календарь и напоминания

События — с напоминаниями или без, с датой или без, у потока или сами по себе. Времени «следующего
захода в поток» нет: поток живёт точками. Сам через cron ничего не планируй.

| Что нужно | Команда |
|---|---|
| Событие | `$F event "Пойти к стоматологу" --when "2026-10-31 15:00" [--remind 1h] [--flow …] [--note "адрес"]` |
| Событие без даты («когда-нибудь») | `$F event "Купить зимнюю резину"` |
| «Покажи календарь», «что у меня ближайшее» | `$F calendar` (вывод — как есть) |
| Отложить / перенести / напоминать / отменить | `$F move [событие] --snooze 15m` · `--when "…"` · `--remind 2h` · `--remind none` · `--cancel` |
| Вернуть убранное кнопкой `/x` | `$F move <событие> --restore` |

- `event`: название коротко, с глагола (это первая строка уведомления), детали — `--note`; по теме
  потока — `--flow`. Несколько напоминаний о разном — несколько `event`.
- «Напомни …» → сразу `--remind` («в само время» → `0`, «за час» → `1h`, «за день и за час» →
  `1d,1h`). «Запиши в календарь» с датой, без «напомни» → без `--remind` и спроси: «Напомнить? За
  сколько?» Без даты — просто сохрани, не спрашивай.
- Относительные даты («во вторник», «завтра») переводи в ГГГГ-ММ-ДД сам. Нет времени, а напомнить
  просят — спроси время. Напоминание без даты не ставится.

**Ответ на напоминание:** `move` без названия берёт событие из последнего напоминания.
«Отложи на 15 минут» → `--snooze 15m`; «перенеси на четверг 20:00» → `--when "2026-10-29 20:00"`
(напоминания сдвигаются вместе); про другое событие — назови его: `$F move стоматолог --when …`.
