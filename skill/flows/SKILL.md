# Потоковый органайзер

Поток (реклама, продажи…) — цепочка **точек**, точка = один заход в работу. У потока **одна
открытая точка**: в неё в хвост пишутся **задачи**, **контекст** (что сделано, ссылки,
контакты), **комментарии** (заметки к точке; **идея** — комментарий с 💡, скрипт ставит лампочку сам). **Выводы** — только у потока целиком (`_выводы.md`).
Сделанную задачу хозяин скрывает кнопкой `/xK` (остаётся с ✓). Завершённые точки — история.
**Указатель** стоит на точке потока или нигде; его ставит любая запись, `continue`, `show`, `use`,
кнопки; `/list` снимает. Кнопки (`/list`, `/1`, `/prev`…) и их экраны — дело скрипта.

Работать **только через скрипт**, его вывод короткий — файлы хранилища не читай:
```
F="python3 $HOME/.hermes/scripts/flows.py"   # не ~ : в кавычках тильда не раскрывается
```
Скрипт сам находит поток по названию, синониму или словоформе, выбирает точку, ставит даты.

**Справка по редкому — читай только когда нужно** (`skill_view flows <файл>`):
- метка `[voice:<id> …]` (длинная голосовая) → `references/voice.md`;
- календарь, «напомни…», «что у меня ближайшее», ответ на напоминание → `references/calendar.md`;
- поиск, теги, входящие, отдельная точка, приоритет/пауза/удаление потока, отмена записи,
  синхронизация → `references/more.md`.

## Команды

| Что нужно | Команда |
|---|---|
| Запись | `$F add <поток\|.> задачи\|идеи\|контекст\|комментарии\|выводы "текст" --short "заголовок"` |
| Многострочная запись | `printf '%s' "текст" \| $F add . контекст -` |
| «Начинаем новую точку / позицию» | `$F new-point <поток\|.> [--title "…"]` (вывод — карточка, как есть) |
| «Продолжаем работать в …» | `$F continue <поток>` |
| «Что по …», «на чём остановился» | `$F show <поток>` |
| «Покажи потоки» | `$F status` |
| «Покажи выводы по …» | `$F collect <поток> выводы` (как есть) |
| Новый поток | `$F new-flow "Название" --priority 1\|2\|3` (1 — главный; не назван — 2, скажи об этом) |
| «Задача про … сделана» | `$F open <поток>`, затем `$F hide K`; вернуть — `$F unhide <поток> "кусок"` |
| Заголовок / выжимка точки | `$F title . "…"` · `$F summary . "одна фраза"` |
| Заголовок записи задним числом | `$F brief . "кусок текста" "заголовок"` |
| «Это идея, а не комментарий» | `$F undo --to идеи` |

Кнопки, если дошли до тебя: `/list` → `$F nav list`, `/N` → `$F nav open N`, `/prev` `/next`
`/point` → `$F nav …`, `/comments` → `$F nav card комментарии`, `/done` → `$F nav card done`, `/full` `/zip` → `$F nav full|zip`, `/conclusions` → `$F nav conclusions`,
`/calendar` → `$F nav calendar`, `/xN` → `$F hide N`. Вывод — как есть.

## Как писать

- Поток назван → он. Не назван → сразу `add .` (пишет в поток под указателем). Ответ «Текущий
  поток не задан» → спроси «К какому потоку это?» и покажи номера из `$F status`.
- Всё — в открытую точку, даже если хозяин листает старую. Старая — только если явно назвал
  (`--point 2026-10-20`). Выводы скрипт сам кладёт в выводы потока.
- Разделы: **задачи** — что сделать; **идеи** — «а что если», почти дословно (`add . идеи` → комментарий с 💡); **контекст** — что
  сделано, ссылки и пути дословно; **комментарии** — как прошло, что заметил; **выводы** — «понял
  что», «оказалось», почти дословно.
- `--short` — заголовок 2–6 слов, суть, у каждой задачи и идеи и у длинной записи любого раздела.
- «На сегодня всё», «закончил» — не новая точка (переспроси, если неясно).
- Новая тема без потока — предложи создать, молча не создавай. Мысль ни к чему — `$F note "…"`.

## Ответ (Telegram)

Коротко. Первая строка — метка места, дальше что записано; перечисления — списком (`– …`),
каждый пункт с новой строки, никогда через «;». Вывод скрипта показывай как есть.
```
📍 Реклама · 23.10 «Статичные креативы готовы»
✓ Контекст +2 · Комментарии +1 · Задачи +2
```
`status`/`show` — перескажи коротко, сохраняя структуру (прошлая точка: задачи, сделано,
комментарии; сейчас: задачи). Хозяин отвечает номером → `show` этого потока.

## Нельзя

- Переписывать файлы хранилища вручную, читать `sources/` без просьбы.
- Выдумывать задачи, идеи, выводы; «улучшать» формулировки.
- Отмечать задачи выполненными самому (только кнопка или прямая просьба), переносить их руками.
- Удалять поток без переспроса (см. `references/more.md`).

Строки `✓ … +N` нет — запись не прошла, покажи ошибку.
