# Еженедельный обзор (с нейросетью)

Напоминания работают без нейросети. Раз в неделю полезен обзор,
где Hermes думает: что забыто и что из этого важно.

```bash
hermes cron create "0 18 * * 0" \
  "Еженедельный обзор потоков хозяина. Выполни: python3 ~/.hermes/scripts/flows.py status --all. Для потоков с пометкой ⚠ и для двух самых приоритетных выполни show <поток>. Затем коротко, для Telegram: 1) какие потоки давно не трогались и почему это может быть важно (опирайся на их выводы и задачи следующей точки); 2) что запланировано на ближайшую неделю (flows.py calendar --days 7); 3) что лежит во входящих неразобранным; 4) предложения: что закрыть, что поставить на паузу, какие приоритеты поднять или опустить. Сам ничего не меняй — только предложения." \
  --skill flows --deliver telegram --name flows-weekly
```

`0 18 * * 0` — воскресенье 18:00 по времени сервера.
